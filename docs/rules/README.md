# Regolamenti

La base documentale iniziale e' il regolamento RCJ Rescue Line **2026**, usato come
provvisorio per il progetto 2027.

## File presenti

- `RCJRescueLine2026-final.pdf` — regolamento specifico Rescue Line 2026.
- `general-rules.pdf` — regole generali RCJ associate.

## Stato e aggiornamento

- Non dichiarare che questi PDF siano il regolamento ufficiale 2027.
- Quando sarà pubblicato il regolamento 2027, confrontare ogni requisito, dimensione, penalità
  e procedura di gara.
- Registrare le differenze in `docs/DECISIONS.md` prima di modificarne l'implementazione.
- Il PDF é il riferimento leggibile; le note hardware devono comunque essere verificate sul
  robot e sul campo.

## Criteri da riesaminare

- percorso e marcature;
- quote e materiali dei tratti speciali;
- regole per vittime, zona di evacuazione e goal;
- procedure di sicurezza, timeout e prover;
- requisiti elettrici, batterie e connettori.
